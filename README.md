# 🎮 Word Scramble Game – Python Project

## 📌 Project Description
Word Scramble Game is a simple Python-based game where players need to guess the correct word from a randomly shuffled set of letters.

The program selects a random word from a predefined list, shuffles its letters, and asks the player to identify the original word.

## 🚀 Features
- Random word selection
- Automatic letter shuffling
- User input for guessing the word
- Case-insensitive answer checking
- Displays the correct answer when the guess is wrong

## 🛠️ Technologies Used
- Python
- Random Module

## 💻 How to Run the Project

1. Clone this repository:
   ```bash
   git clone YOUR_REPOSITORY_LINK
   ```
2. Open the project in Python or VS Code.
3. Run the Python file:
   ```bash
   python project.py
   ```
4. Enter your guess and check the result!
